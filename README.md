# TP – Fuzzy C-Means

TP de Master 2 Informatique (VMI) : segmentation d'images avec l'algorithme Fuzzy C-Means implémenté en Python.

## Contenu

- `TP_Fuzzy_CMeans.ipynb` : implémentation de Fuzzy C-Means et segmentation en niveaux de gris (K=2) et RGB (K=3)
- Cartes de chaleur des degrés d'appartenance, segmentation finale, figures des clusters et courbes de convergence

## Exécution

Installer les dépendances avec `pip install -r requirements.txt`, puis placer les deux images `milky-way-nvg.jpg` et `milky-way.jpg` dans le même dossier que le notebook et exécuter les cellules dans l'ordre.

**Note :** les deux fichiers image ne sont pas encore inclus dans ce dépôt. Les images utilisées dans le TP doivent être ajoutées pour exécuter le notebook localement.
